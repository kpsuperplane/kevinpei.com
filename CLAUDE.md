# kevinpei.com

Personal website built with Astro.

## Stack

- **Framework**: Astro
- **Package manager**: Bun — use `bun` instead of `npm` or `node` for all commands (e.g. `bun install`, `bun run dev`)

## Styling

- Write clean, simple CSS directly in Astro component `<style>` blocks
- Do not use CSS libraries or utility frameworks (e.g. no Tailwind)

## Philosophy 

* mobile compatible
* extremely fast and lightweight
